# Maintainers

This file does not assign or invent individual maintainers. Repository permissions are the authoritative record of who currently has administrative or maintainer access.

## Roster

No named maintainer roster is published in this repository yet. The repository owner should add a person or team here only after appointment and confirmation of their responsibilities.

## Responsibilities

Maintainers review contributions, preserve project security principles, maintain CI and repository settings, triage issues, coordinate vulnerability response, and document material decisions. See [GOVERNANCE.md](GOVERNANCE.md).

## Future roster format

When maintainers are appointed, list their GitHub handle, role, and (if appropriate) areas of responsibility. Keep CODEOWNERS synchronized. Do not add an address or account without the maintainer's consent.
