# Security and Governance

**Proposed framework, not active policy.** Consent is separate for submission, receipt, alerts, enforcement. SADA has no Discord token/action. Findings are explainable; high-impact decisions require human review; appeals, correction, audit, retention and safe failure are mandatory. Name policy owner, operator, reviewers, appeal reviewer and security/privacy contact before launch. See [standards](../shared-standards/README.md) and [decisions](../implementation-roadmap/06-open-questions-and-decisions.md).
