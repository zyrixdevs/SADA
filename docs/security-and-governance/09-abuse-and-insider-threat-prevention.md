# 09 — Abuse and insider threat prevention

Source poisoning: provenance, independence caps, anomaly quarantine, corrections, review. Reviewer abuse: least privilege, separation, quorum, conflict disclosure, reasoned votes, access review. Operator abuse: scoped access, break glass, dual control, independent audit. No opaque permanent reputation; appeal count alone is not negative trust. Caps/suspension require notice and challenge path.

## Response controls

Source quarantine is scoped to the affected credential or event type, has a reason and expiry, and cannot erase prior reports. Reviewer votes are independent records; quorum checks unique authorized reviewers and conflicts inside the transaction. Break-glass access expires automatically and triggers a post-use review by an independent operator.
