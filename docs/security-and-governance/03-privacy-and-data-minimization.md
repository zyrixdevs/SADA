# 03 — Privacy and data minimization

Collect declared fields for explicit purpose/consent; disclose recipients, retention, access and action effect. Exclude private-message bodies, unrelated history, IP/device fingerprints, secrets and indiscriminate member streams. IDs are sensitive in context. Raw reasons/evidence narrower than summaries. No public accused list. Legal basis, notice, access/deletion rights and controller/operator roles need review; make no unapproved promises.
## Data inventory gate

For every field record purpose, source, sensitivity, recipient, retention class, access role, and deletion path. Reject undeclared fields at the adapter and API. Do not place identifiers in metric labels or logs. Use aggregate values only when the feature can meet its purpose without member-level history, and document the cohort floor before exposing dashboards.
