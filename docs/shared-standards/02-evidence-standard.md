# 02 — Evidence standard

Reference includes ID/type, source system/actor, guild, capture/observation times, provenance, digest if relevant, access scope, redaction, retention, linked revision. Keep separate facets for auth, audit match, attribution, completeness, time consistency, integrity, reviewer, correction. Hash proves byte equality, not truth. Prefer references; copied artifact requires purpose, consent, minimization, encryption, access audit and expiry. Missing source is unavailable.
## Reviewer display contract

A reviewer view distinguishes source-provided material, derived summaries, redactions, and reviewer annotations. Include unavailable references and integrity failures rather than hiding them. Access decisions are scoped to case, purpose, and expiry; exports are separately authorized and watermarked with request/audit ID. Do not store downloaded Discord content merely because a reference is inaccessible.
