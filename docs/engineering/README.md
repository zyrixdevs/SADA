- [CI/CD strategy](CI-CD-STRATEGY.md) — working repository CI and gated future application/release pipeline.

- [Release process](RELEASE-PROCESS.md) — current no-release state and future signed release procedure.
- [Quality assurance](QUALITY-ASSURANCE.md) — current checks, commands, coverage boundaries, and future test strategy.
- [Third-party notices](THIRD-PARTY-NOTICES.md) — licenses for adopted policy text and tooling.
