# Support

SADA is an early, documentation-only open-source project. There are no released binaries, hosted services, or implemented feature modules to support.

- **Documentation correction or question:** open a [documentation issue](https://github.com/zyrixdevs/SADA/issues/new?template=documentation.yml).
- **Future feature proposal:** use the [feature proposal form](https://github.com/zyrixdevs/SADA/issues/new?template=feature_request.yml) and distinguish a design proposal from a bug in existing documentation/tooling.
- **Repository tooling problem:** use the [bug report form](https://github.com/zyrixdevs/SADA/issues/new?template=bug_report.yml).
- **Security issue:** use only the private process in [SECURITY.md](SECURITY.md); do not file a public issue.

Please include the document path, expected behavior, and sanitized reproduction details. Do not post credentials, real Discord member information, private conversations, or production evidence. Community support is best effort; no response-time commitment is currently provided.
